## 实践方向与技术方案

- **企业知识问答与业务平台：** 具备 RAG 知识库部署、复杂表单、权限体系、低代码及数据可视化实践，能够衔接 Web、移动端与服务端能力。
- **AI 语音交互与学习应用：** 使用 React Native / Expo、Zustand 和 RxJS 组织多阶段交互，衔接 ASR、LLM 流式回复与 TTS，处理请求取消、异步竞态和异常恢复；结合 Embedding 召回历史上下文。
- **内容生产与自动化：** 使用 Python、Pydantic 和 LLM API 编排生成、审校与限次修复，通过版本化缓存和执行进度持久化支持中断恢复，并校验内容与音频的发布一致性。
- **工具集成与任务执行：** 基于 MCP SDK、Zod 定义工具输入及结果契约，结合持久化任务、幂等键、重试上限和超时回收组织多步骤流程。
- **端侧语音助手：** 使用 Swift / SwiftUI、本机模型与系统 API 探索语音操作，通过动作白名单、字段校验和用户确认分离模型规划与确定性执行，已完成 Demo 可行性验证。

## 技术方向

- **主场 · React Native / Expo 移动端：** TypeScript、Zustand、RxJS；iOS / Android 双端适配、复杂状态与异步交互、性能优化及应用发布。
- **扩展技能 · Web 与小程序：** React / Next.js、Vue、微信原生小程序、uni-app；组件化、复杂表单、数据可视化与接口集成。
- **老本行 · iOS 原生：** Objective-C / Swift；原生 SDK 集成、模块接入与跨端通信。
- **持续扩展 · AI 应用：** LLM API、Embedding / RAG、MCP、ASR / TTS；结构化输出、工作流编排与评测回归。
- **业务需要 · 服务与数据：** Python / FastAPI、TypeScript 服务端、PostgreSQL；API 集成、访问控制与任务持久化。
- **上线以后 · 工程交付与运行维护：** GitHub Actions、GitLab / Jenkins、Docker、Harbor、Kubernetes；持续集成、容器化部署与线上问题排查。
