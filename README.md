# FengMr

**AI 应用工程师｜LLM 工作流、MCP 与语音交互｜React Native / Next.js 全栈研发与交付**

10 年软件研发经验，专长于前端与跨端开发，关注 AI 应用从交互设计、服务集成到部署维护的完整交付。

## 实践方向与技术方案

- **企业知识问答与业务平台：** 具备 RAG 知识库部署、复杂表单、权限体系、低代码及数据可视化实践，能够衔接 Web、移动端与服务端能力。
- **AI 语音交互与学习应用：** 使用 React Native / Expo、Zustand 和 RxJS 组织多阶段交互，衔接 ASR、LLM 流式回复与 TTS，处理请求取消、异步竞态和异常恢复；结合 Embedding 召回历史上下文。
- **内容生产与自动化：** 使用 Python、Pydantic 和 LLM API 编排生成、审校与限次修复，通过版本化缓存和执行进度持久化支持中断恢复，并校验内容与音频的发布一致性。
- **工具集成与任务执行：** 基于 MCP SDK、Zod 定义工具输入及结果契约，结合持久化任务、幂等键、重试上限和超时回收组织多步骤流程。
- **端侧语音助手：** 使用 Swift / SwiftUI、本机模型与系统 API 探索语音操作，通过动作白名单、字段校验和用户确认分离模型规划与确定性执行，已完成 Demo 可行性验证。

## 技术方向

- **AI 应用：** LLM API、MCP、结构化输出、Embedding / RAG、ASR / TTS、评测与工作流编排。
- **前端与跨端：** TypeScript、React Native / Expo、React / Next.js、Vue、Zustand、RxJS。
- **服务与数据：** Python / FastAPI、PostgreSQL、API 聚合与访问控制。
- **工程交付：** GitHub Actions、GitLab / Jenkins、Docker、Harbor、Kubernetes。
