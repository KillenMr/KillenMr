# Local Voice Actions｜端侧语音操作助手

[返回主页](../README.md)

**个人项目，开发中；已完成 Demo 验证，确认方案可行性。**

使用语音或文字描述需要记录的事项，由本机模型生成候选动作，经规则校验及用户确认后，调用健康、日历与提醒事项工具。

**技术：** Swift / SwiftUI、Qwen3、llama.cpp、Apple Speech、HealthKit、EventKit。

## 处理流程

1. 接收语音或文字输入，生成转写文本。
2. 本机模型输出结构化候选动作。
3. 使用动作白名单、字段约束及原文数值校验，生成可确认的计划。
4. 由确定性执行器按工具申请权限并执行，逐项展示结果。

## 工程重点

- **规划与执行分离：** 模型提出候选动作，实际调用由通过校验的计划和确定性执行器控制。
- **参数约束：** 检查工具名、字段与原文数值，限制不受支持的动作和不匹配的参数。
- **权限与回执：** 按工具申请系统权限，执行前持久化操作状态并逐项反馈结果。
- **异常处理：** 对结果不确定的操作提示人工核查，避免将未知状态直接当作成功。
